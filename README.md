**Checqin Booking** — это высокопроизводительная, модульная и гибкая экосистема для поиска, бронирования отелей и аренды частного жилья (апартаментов, коттеджей). Разработано на базе современного веб-стека Ruby on Rails в соответствии с лучшими практиками проектирования корпоративных систем.

---

## 🚀 Основной функционал (Core Features)

*   **Умный поиск и фильтрация:** Поиск жилья по городам, датам заезда/выезда, количеству гостей, диапазону цен и типу размещения (отели, хостелы, апартаменты). Сортировка результатов по возрастанию и убыванию цены.
*   **Две модели размещения:**
    *   `Hotel` (Отели, хостелы, базы отдыха) — имеют сложную структуру с отдельным каталогом номеров (`Room`).
    *   `Property` (Частные квартиры, студии, коттеджи) — сдаются целиком как единый объект.
*   **Система ролей на базе Pundit:**
    *   👤 `User (Клиент)` — ищет жилье, добавляет в избранное, осуществляет бронирование, оставляет отзывы после поездки.
    *   🏢 `Supervisor (Партнер/Менеджер)` — управляет собственными отелями и апартаментами, добавляет номера, одобряет бронирования клиентов.
    *   👑 `Admin (Администратор)` — контролирует систему, модерирует все входящие объекты (отели и квартиры), подтверждает или отклоняет публикации.
*   **Двухэтапная публикация (Модерация):** Все новые объекты от супервайзоров отправляются на модерацию. Администратор в специальном кабинете изучает полную информацию об объекте и принимает решение об одобрении. Только одобренные объекты видны в поиске.
*   **Асинхронные уведомления:** Фоновые задачи (Sidekiq + Redis) для автоматической отправки транзакционных писем (`BookingMailer`) при создании, подтверждении и отмене бронирований.
*   **Избранное (Favorites) & Отзывы (Reviews):** Удобный личный кабинет со списком сохраненных отелей и возможностью оценки проживания.

## 🛠️ Технологический стек

*   **Backend:** Ruby 3.3.5 / Ruby on Rails 7.1.3 (MVC, Active Record, Active Job)
*   **Database:** PostgreSQL 15 (Оптимизированные индексы, внешние ключи, констрейнты)
*   **Caches & Background Jobs:** Redis 7 / Sidekiq (асинхронная отправка почты)
*   **Auth & Security:** Devise (сессии, регистрация) + Pundit (политики авторизации)
*   **Frontend:** HTML5 / TailwindCSS (внедрен в админ-панель для премиального UX)
*   **Storage:** Active Storage (загрузка фотографий объектов)
*   **Testing:** RSpec / FactoryBot / Shoulda Matchers / Database Cleaner

## 📦 Быстрый запуск проекта

Для удобства развертывания проект полностью подготовлен к запуску через **Docker Compose**. Вам не нужно устанавливать Ruby, PostgreSQL или Redis локально.

### Вариант А: Запуск через Docker (Рекомендуемый)

1.  **Склонируйте репозиторий и перейдите в папку проекта:**
    ```bash
    git clone https://github.com/galactazavr/booking_2-develop.git
    cd booking_2-develop
    ```
2.  **Запустите все сервисы одной командой:**
    ```bash
    docker-compose up --build
    ```
    *Эта команда поднимет PostgreSQL, Redis, Rails-сервер (на порту 3000) и Sidekiq-воркер в фоновом режиме.*

3.  **Инициализируйте базу данных и заполните её демонстрационными данными (в новом окне терминала):**
    ```bash
    docker-compose exec web rails db:prepare db:seed
    ```

### Вариант Б: Локальный запуск (Без Docker)

1.  **Установите системные зависимости (зависит от вашей ОС):**
    *   Убедитесь, что у вас установлены `Ruby 3.3.5`, `PostgreSQL` и запущен `Redis`.
2.  **Установите гемы:**
    ```bash
    bundle install
    ```
3.  **Настройте базу данных в `config/database.yml`:**
    *   Проверьте учетные данные подключения к вашему локальному PostgreSQL.
4.  **Создайте и инициализируйте базу данных:**
    ```bash
    bin/rails db:create db:migrate db:seed
    ```
5.  **Запустите Redis-сервер и Sidekiq (в отдельном процессе):**
    ```bash
    bundle exec sidekiq
    ```
6.  **Запустите Rails веб-сервер:**
    ```bash
    bin/rails server
    ```

## 📂 Структура проекта и ключевые модули

*   `app/models` — Бизнес-модели (`Hotel`, `Room`, `Property`, `Booking`, `Review`, `Favorite`, `User`).
*   `app/controllers/supervisor` — Контроллеры личного кабинета партнера (создание отелей, управление бронированиями).
*   `app/controllers/admin` — Контроллеры панели администратора для модерации и подтверждения публикаций.
*   `app/policies` — Pundit-политики доступа (например, `HotelPolicy`, `BookingPolicy`), разграничивающие доступ к ресурсам.
*   `app/mailers` — Почтовый класс `BookingMailer` для отправки красивых HTML-уведомлений о статусах бронирований.
*   `spec` — Интеграционные, юнит- и policy-тесты для обеспечения стабильности кодовой базы.
